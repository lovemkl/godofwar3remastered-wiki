No hardware preset on this wiki has been independently benchmarked. The earlier 4GB VRAM, RX 6700 XT and 4K/240 FPS recipes lacked linked test records and have been withdrawn.

## Start with the Exact Release

Open the [maintainer release notes](https://github.com/FelipePrado0/SpartanPort/releases/tag/windows-v2.7.0) and record the version you actually use. Published measurements apply to their listed conditions; they do not guarantee the same result for your processor or scene. A selectable frame-rate limit is not a measured frame rate.

## Record a Baseline

| Field | Record before comparison |
|---|---|
| Software | Release tag, game ID/version, OS, graphics driver |
| Hardware | CPU, GPU, RAM and display refresh rate |
| Settings | Resolution, frame limit, enabled patches and overlays |
| Scene | Save/checkpoint, route and measurement duration |
| Result | Average FPS, low points, frame-time spikes and visible defects |
| Cache | First run or later run; note any compilation |

Keep the same scene and route when changing one setting. Include an ordinary gameplay section and a demanding section; one smooth opening does not prove that the rest of the campaign behaves identically. Preserve your baseline and saves so changes are reversible.

## Feature Availability

Check the [README feature table](https://github.com/FelipePrado0/SpartanPort#feature-availability) for the exact package. Earlier FSR tuning recipes should not be applied when the feature is disabled in that release. Do not assume every option described in an old article appears in your build.

## Report a Problem

Record the error and conditions before changing files. Use the [maintainer issue tracker](https://github.com/FelipePrado0/SpartanPort/issues) and attach relevant logs after removing private account or filesystem details. Follow the [installation source checks](/guide/how-to-install); blanket security exclusions and unexplained privilege changes are not performance fixes.
