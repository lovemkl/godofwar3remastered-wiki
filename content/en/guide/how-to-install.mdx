## What the Maintainer Requires

The [project README](https://github.com/FelipePrado0/SpartanPort#download-and-play) lists Windows 10/11, an AVX-capable 64-bit CPU, Vulkan 1.3 graphics and the user's own supported PS4 game dump. The project does not include game files. It also documents an experimental Linux build. Read the instructions belonging to your chosen release rather than assuming every main-branch feature is included.

The maintainer provides a launcher. An older version of this article incorrectly treated any launcher as a fake; a launcher alone is not evidence either way. Verify the repository, release and file identity.

## A Careful Installation Sequence

1. Read the versioned release notes and current prerequisites. Check your operating system, graphics driver, game build and asset choice against them.
2. Keep an untouched backup of your own game files and saves. Record the release and settings you intend to test.
3. Compare the downloaded file with any checksum or signature published by the maintainer. Stop if a value differs; do not substitute a random mirror.
4. Keep security protection enabled. If software is blocked or quarantined, stop and investigate the exact detection with the maintainer and security provider. An unsigned program is not automatically safe or malicious.
5. Follow the release's extraction and launcher instructions using ordinary user permissions. This guide does not recommend blanket antivirus exclusions, disabling protection or running as administrator to overcome an unexplained failure.
6. After any successful launch, record the exact build, hardware, settings and observed behavior. A title screen is not proof that a full campaign is completable.

## Troubleshooting Without Guessing

For a failure, preserve its error text and relevant logs before changing settings. Report the release tag, operating system, CPU, GPU, driver, game title ID and version, and a short reproduction sequence to the [maintainer's issue tracker](https://github.com/FelipePrado0/SpartanPort/issues). Remove personal paths or account details before sharing logs.

Change one setting at a time and keep a way to undo it. Avoid deleting saves, clearing unrelated folders or elevating privileges merely because another user's setup differed.

## What the Performance Claims Mean

The maintainer documents resolution and frame-rate options; a selectable 240 FPS setting is not a measured 240 FPS result on your PC. Our site has not independently reproduced 4K performance, hardware minimums or a complete playthrough. Early press claims should not be treated as current benchmark evidence.

The README's feature-availability table marks FSR options disabled in the versions it describes. Check your release before following older FSR tuning advice. [Release 2.7.0 notes](https://github.com/FelipePrado0/SpartanPort/releases/tag/windows-v2.7.0) contain specific measurements and test limitations; they are maintainer/player reports, not tests by this wiki.
